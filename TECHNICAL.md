### 3.4 Memory system

- Layer 1 (local): `~/.hermes/memories/MEMORY.md` — ≤4000 chars, injected every session; contains operating state, conventions, incident learnings. Cap is CHARACTERS (4000) not bytes - on-disk byte size runs higher due to multi-byte chars (e.g. arrows). Edits must replace/remove to stay under cap.
- Layer 2 (MCP): Cloudflare agent-memory (`memory_mcp` tools, scope `user:hp-sn`). Save triggers: SHIPPED/CHANGED/DECIDED/BROKE/LEARNED. Tags are accepted but ignored — retrieval is text-semantic only. Front-load dates/subjects; max 3 entries per work arc, 25/week.

## 7. Secrets architecture

## 9. Failure modes & runbooks

| Failure | Impact | Runbook |
|---|---|---|
| OpenBao down | Secret fetch fails across jobs; Telegram alerts still work (notify script falls back to cached `config/telegram_token`) | Fix OpenBao first; notify failures append to `~/.hermes/state/notify_failed.log` |
| LiteLLM/Postgres down | ALL AI features down (Hermes, HA voice, OpenWebUI) | docker compose restart; check DB container health; Ollama :11434 still direct-usable |
| Cloudflare outage | CF-routed models, Kitesurf browser, remote memory degrade | Fallbacks to OpenRouter models automatic; local models unaffected |
| Provider reshuffle | Channel groups/EPG drift, categories renamed | Run `iptv-maint override-restore`, `epg-refresh`; check job warnings for renamed categories |
| IPsec tunnel down | Remote access via tunnel affected | Watchdog alerts; Phase 2 ladder if unlocked |
| Emby disk full | Syncs fail | `/datadrive` capacity check before large syncs |

## 10. Cross-agent etiquette

- When modifying `jobs.json`: use the transaction helper (§3.5) or back up first; never rewrite whole file from stale snapshots.
- When editing config.yaml: backup with dated suffix; YAML-parse after edit; restart gateway only from outside its process.
- When touching nuc2 media state: pre-backup state files; verify post-conditions (file counts, JSON validity); never delete `Trash/` manifests.
- Reporting: plain-English first line + status emoji; machine detail stays in logs/output files, not Telegram.
- Memory: save SHIPPED/CHANGED/DECIDED/BROKE/LEARNED to MCP memory with dates front-loaded; keep MEMORY.md ≤4000 chars.
